Recovery Probe

…

Choose the mapfile in step 2 to see where the old drive was damaged.

  1. Check the program works on this PC

    The program checks itself on sample files and a small damaged test disk it carries, where every right answer is known. It takes a few seconds and touches nothing of yours.

  2. Your ddrescue mapfile

    The mapfile is the small file ddrescue wrote while it copied the old drive. It lists every place on the drive it could not read. If there was more than one attempt, choose the last one.

  3. Connect the recovered SSD, protected

    When a drive is plugged in, Windows starts using it straight away and can write to it on its own. On the only copy of your files that must not happen, so here it arrives switched off, the program marks it read-only, and Windows' setting goes back to normal.

  4. See what the damage touched

    The program reads the recovered SSD directly (it never writes to it) and works out which files and folders sit on the places ddrescue never read, and which files Windows cannot even list.

  5. Copy everything off the SSD

    Every file and folder is copied straight off the SSD into a folder on another drive: also the files Windows cannot list, and the data no folder names any more. Choose an empty folder on a drive with room for everything, such as SPARE\WORK.

  6. Check every copied file

    Every file’s structure is read to find damage that looks fine on screen: a photo cut short, a block of zeros where the drive could not be read. With the results of step 4, a file the drive lost data from is marked NEVER_READ even when it looks fine.
